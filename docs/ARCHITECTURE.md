# 公开版架构

```text
浏览器
  ├─ 页面外壳（Server Component）
  ├─ 交互沙箱（Client Component）
  └─ 合成场景 JSON（mock: true）

Next.js 服务
  └─ GET /api/health（只读、无外部依赖）
```

公开版没有数据库、登录、后台任务、外部 API、模型调用或消息发送。点击“模拟执行”只在 React 组件中更新本地展示状态，刷新页面即恢复。

## 与生产系统的边界

生产系统承担真实渠道、权限、数据持久化、AI 执行、安全护栏和经营归因。本仓库只公开这些能力在操作界面中的**抽象结果形态**，不公开实现路径、接口合同或核心规则。
