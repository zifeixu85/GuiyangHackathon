# Security Policy

## Supported scope

This repository is a synthetic, non-production showcase. It does not accept credentials and does not connect to production services.

## Reporting a problem

Please open a GitHub issue for a vulnerability that only affects this public showcase. Do not include secrets, personal information, production URLs, exploit payloads, or data copied from another system in the issue.

For a report that may affect a non-public system, contact the project owner through an existing private channel instead of posting details publicly.
